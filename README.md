# PureLabel

PureLabel is an iOS app built with SwiftUI that helps users capture and process label information from photos.

## Project Structure

- `PureLabel/`: App source code, views, processing logic, and assets.
- `PureLabel.xcodeproj/`: Xcode project configuration.

## Running the App

1. Open `PureLabel.xcodeproj` in Xcode.
2. Select an iOS simulator or connected device.
3. Build and run the project.

## GitHub Setup

- Keep source code and project files versioned.
- Ignore local machine and build artifacts via `.gitignore`.
- Use clear commit messages and open pull requests for feature changes.
