# PureLabel

PureLabel is an iOS app that lets users take a photo or upload an image of a record label, extract only the label, and export it with a transparent background for repurposing in design, video, and other creative workflows.

## Project Structure

- `PureLabel/`: App source code, views, processing logic, and assets.
- `PureLabel.xcodeproj/`: Xcode project configuration.

## Running the App

1. Open `PureLabel.xcodeproj` in Xcode.
2. Select an iOS simulator or connected device.
3. Build and run the project.

## GitHub Setup

- Keep source code and project files versioned.
- Ignore local machine and build artifacts via `.gitignore`.
